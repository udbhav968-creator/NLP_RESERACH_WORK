# Team Project Documents (.docx)

This folder contains all official editable Microsoft Word (`.docx`) project deliverables for the **EnHi-LMP** project (*CSET 346: Natural Language Processing*, Bennett University, supervised by Dr. Surabhi Solanki).

---

### Available Documents in this Folder

| File Name | Description & Contents | Target Audience / Use |
|---|---|---|
| 🏆 **`Final_Evaluation_Report.docx`** | Official Final Evaluation Report detailing the 5 research gaps, empirical benchmarks (E1–E5), 683 real pairs, human agreement ($\alpha = 0.966$), and in-browser verification proofs. | Faculty final evaluation, viva defense & academic review |
| 📘 **`EnHi_LMP_Complete_Project_Documentation.docx`** | Comprehensive 10-chapter technical report detailing the 5 research gaps, CUAD/ToS;DR/MTA corpus provenance (683 pairs), double-blind human annotation ($\alpha = 0.966$), system architecture, all quantitative benchmarks (E1–E5), and deployment. | Faculty evaluation, external review, and project documentation |
| 📑 **`NLP_Mini_Project_Report.docx`** | The official Bennett University CSET 346 course mini-project report template, updated with final human gold metrics and deployment URLs. | Official university course submission |
| 📄 **`LMP_IEEE_Paper.docx`** | Complete conference research paper formatted according to standard IEEE two-column specifications. | Academic publication & conference defense |
| 🛡️ **`Slide_Explanation_Guide.docx`** | Detailed slide-by-slide explanation guide and Q&A defense preparation document. | Viva defense, presentation preparation, and team reference |
