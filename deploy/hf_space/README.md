# Legal Meaning Checker (EnHi-LMP)

Scores whether a plain-language rewrite of an English or Hindi insurance / tenancy clause keeps its legal meaning
(1–10, JUDGEBERT scale), decides Preserved / Partially / Not preserved, and explains the legal change.

* Web app: this Space's main page · REST API: `/api/score`, `/api/batch`, `/api/batch/csv`, `/api/feedback`, `/api/history`, `/api/stats` · docs: `/docs`
* Code, data and paper: https://github.com/udbhav968-creator/NLP_RESERACH_WORK
