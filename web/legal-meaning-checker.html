Legal Meaning Checker

Checks whether a plain-language rewrite of an insurance or tenancy clause keeps its legal meaning. It scores the pair on the 1–10 JUDGEBERT scale, decides whether the meaning is preserved, and names the legal change it found.

Model vs. human scores

Every “Send my score” on the Check page becomes a human label. They are the start of the human annotation that will replace the silver labels.

About the model

Not preserved · below 4.5A core rule changed: a duty, condition, number, deadline or party.
Partially preserved · 4.5 to 7.5A secondary detail is lost or blurred.
Preserved · 7.5 and aboveSame legal effect in plainer words.

Measured accuracy

5-fold cross-validation grouped by clause (English and Hindi twins never split), mean of 3 seeds. FrJUDGE is the base paper's French dataset, scored by human annotators.

Known limits

  • Labels are rubric-based silver scores; human double annotation is in progress.
  • Reads one sentence at a time, without definitions elsewhere in the contract.
  • Relies on word lists, so a meaning flip by a different verb can be missed.
  • Faithful rewrites with heavy rewording can score lower than they should.
  • A decision aid for reviewers, not legal advice.

REST API

POST/api/batchScore up to 500 pairs in one call
POST/api/batch/csvUpload a CSV (original,simplification); get it back with scores added

GET/api/statsTotals by decision, error type and language; model-vs-human agreement

    

    

      
Deploy your own copy

      
git clone https://github.com/udbhav968-creator/NLP_RESERACH_WORK.git
cd NLP_RESERACH_WORK

# 1. Run locally (Python 3.10+)
pip install -r api/requirements.txt
uvicorn api.main:app --port 8000          # open http://localhost:8000  ·  docs at /docs

# 2. Or with Docker
docker build -t lmp-checker .
docker run -p 7860:7860 lmp-checker       # open http://localhost:7860

# 3. Public hosting: Hugging Face Spaces (Docker SDK) or Render — see DEPLOY.md
